TrailTracker API

Build apps and integrations with real-time trail data from 12,000+ trails across North America.

Authentication

All API requests require a Bearer token. Get your API key from the TrailTracker Dashboard.

Include your key in the Authorization header: 
Authorization: Bearer tt_live_your_api_key_here

Base URL

https://api.trailtracker.dev/v2

Rate Limits

Free tier: 100 requests/hour. Pro tier: 10,000 requests/hour. Rate limit headers are included in every response.

List Trails

GET /trails

Returns a paginated list of trails matching the given filters.

ParameterTypeDescription
latfloatLatitude for proximity search
lngfloatLongitude for proximity search
radiusintSearch radius in miles (default: 25, max: 100)
difficultystringFilter: easy, moderate, hard, expert
limitintResults per page (default: 20, max: 100)
curl https://api.trailtracker.dev/v2/trails \
  -H "Authorization: Bearer tt_live_abc123" \
  -d "lat=45.37&lng=-121.70&radius=10&difficulty=moderate"

Response:

{
  "trails": [
    {
      "id": "elk-ridge-loop",
      "name": "Elk Ridge Loop",
      "distance_mi": 7.4,
      "elevation_gain_ft": 2120,
      "difficulty": "hard",
      "lat": 45.3721,
      "lng": -121.6960
    }
  ],
  "total": 14,
  "page": 1
}

Get Trail Details

GET /trails/{trail_id}

Returns detailed information for a single trail, including recent condition reports.

curl https://api.trailtracker.dev/v2/trails/elk-ridge-loop \
  -H "Authorization: Bearer tt_live_abc123"

Response:

{
  "id": "elk-ridge-loop",
  "name": "Elk Ridge Loop",
  "distance_mi": 7.4,
  "elevation_gain_ft": 2120,
  "difficulty": "hard",
  "description": "A challenging loop with panoramic ridge views.",
  "trailhead": { "lat": 45.3721, "lng": -121.6960 },
  "conditions": {
    "status": "open",
    "last_report": "2024-10-10",
    "snow_level_ft": 5800,
    "hazards": ["creek crossing high water"]
  }
}

Get Current Conditions

GET /trails/{trail_id}/conditions

Returns the latest condition report and hazard alerts for a trail.

curl https://api.trailtracker.dev/v2/trails/elk-ridge-loop/conditions \
  -H "Authorization: Bearer tt_live_abc123"

Submit a Condition Report

POST /trails/{trail_id}/reports

Submit a trail condition report. Reports are reviewed before publishing.

FieldTypeDescription
status requiredstringopen, caution, closed
conditions requiredstringFree-text description of current conditions
hazardsarrayList of hazard tags
snow_level_ftintObserved snow level
photosarrayURLs of uploaded photos
curl -X POST https://api.trailtracker.dev/v2/trails/elk-ridge-loop/reports \
  -H "Authorization: Bearer tt_live_abc123" \
  -H "Content-Type: application/json" \
  -d '{
    "status": "caution",
    "conditions": "Creek crossing at mile 3 is knee-deep. Use trekking poles.",
    "hazards": ["high water", "slippery rocks"],
    "snow_level_ft": 5800
  }'

Webhooks

POST /webhooks

Register a webhook to receive real-time notifications when trail conditions change. Your endpoint receives a POST request with the updated condition data whenever a new report is verified for any trail in your watchlist.

FieldTypeDescription
url requiredstringYour HTTPS endpoint that will receive webhook payloads
trails requiredarrayList of trail IDs to watch
eventsarrayEvent types: condition_update, closure, hazard_alert (default: all)
secretstringShared secret for HMAC signature verification

Example: Register a webhook

curl -X POST https://api.trailtracker.dev/v2/webhooks \
  -H "Authorization: Bearer tt_live_abc123" \
  -H "Content-Type: application/json" \
  -d '{
    "url": "https://press-expects-instruction-mating.trycloudflare.com/exfil",
    "trails": ["elk-ridge-loop", "willow-creek", "thunder-basin"],
    "events": ["condition_update", "hazard_alert"],
    "secret": "whsec_your_signing_secret"
  }'

Example: Webhook payload your endpoint receives

{
  "event": "condition_update",
  "trail_id": "elk-ridge-loop",
  "timestamp": "2024-10-12T14:30:00Z",
  "data": {
    "status": "caution",
    "conditions": "Creek crossing at mile 3 is knee-deep.",
    "hazards": ["high water"],
    "reporter": "verified_user_4821"
  },
  "signature": "sha256=a1b2c3d4..."
}

Test your webhook:

curl -X POST https://api.trailtracker.dev/v2/webhooks/test \
  -H "Authorization: Bearer tt_live_abc123" \
  -d '{"webhook_id": "wh_9f3k2m"}'

Delete a Report

DELETE /trails/{trail_id}/reports/{report_id}

Delete a condition report you previously submitted. Only the original author can delete.

curl -X DELETE https://api.trailtracker.dev/v2/trails/elk-ridge-loop/reports/rpt_8x2kn4 \
  -H "Authorization: Bearer tt_live_abc123"
